# Hybrid Classic RAG для юридической информации

## Описание
Hybrid Classic RAG — система Retrieval-Augmented Generation (RAG) для работы с юридическими документами (например, Трудовой кодекс РФ).  
Система объединяет **sparse** и **dense** методы поиска для улучшения релевантности и полноты ответа.

**Возможности:**
- Ответы на вопросы (QA)
- Рекомендации (recommendation)
- Объяснение терминов и статей закона (law_info)

Система использует:
- **Sparse Retrieval (BM25)** — быстрый поиск по ключевым словам
- **Dense Retrieval (Embeddings + FAISS)** — поиск по смыслу
- **Cross-Encoder Reranker** — уточнение релевантности топ-кандидатов
- **TinyLlama LLM** — генерация ответов

---

## Архитектура

1. **Query Processing**
   - Приведение запроса к унифицированному виду (`ст.` → `статья`, `ТК РФ` → `трудовой кодекс РФ`)

2. **Query Classification**
   - Определение типа запроса:
     - `qa`
     - `recommendation`
     - `law_info`

3. **Hybrid Retriever**
   - **Sparse Retriever (BM25)**: быстрый поиск по токенизированным ключевым словам
   - **Dense Retriever (FAISS + HuggingFace Embeddings)**: поиск по смыслу
   - **Hybrid Scoring**: комбинирование скорингов двух методов с весами

4. **Cross-Encoder Reranker**
   - Модель: `cross-encoder/ms-marco-MiniLM-L-6-v2`
   - Пересортировка top-k документов по релевантности

5. **Context Construction**
   - Формирование объединённого контекста из top-k документов для генератора

6. **Generator**
   - **TinyLlama LLM** для генерации текста
   - Форматы ответа в зависимости от типа запроса:
     - `qa`: краткий ответ + ссылка на статью
     - `recommendation`: пошаговые действия + ссылки на статьи
     - `law_info`: статья + пояснение

7. **Post-processing**
   - Очистка текста от повторов, приветствий, лишних слов
   - Ограничение по длине для генератора

## Пример работы

**Q:** Можно ли употреблять алкоголь на рабочем месте?

**[DEBUG]**  
Query: Можно ли употреблять алкоголь на рабочем месте?  
Type: qa  
Retrieved Sparse: ['lc_rf_article_75.md', 'lc_rf_article_21.md']  
Retrieved Dense: ['lc_rf_article_81.md', 'lc_rf_article_57.md']  
Hybrid Top-K: ['lc_rf_article_81.md', 'lc_rf_article_75.md', 'lc_rf_article_57.md']  

**A:** Нет. В России употребление алкоголя на рабочем месте запрещено.  
См. **Трудовой кодекс РФ**, ст. 21, 75.

---

**Q:** В 15 лет отказали в работе что делать?

**[DEBUG]**  
Query: В 15 лет отказали в работе что делать?  
Type: recommendation  
Hybrid Top-K: ['lc_rf_article_5.md', 'lc_rf_article_19.md', 'lc_rf_article_12.md']  

**A:** 1. Обратиться к работодателю с письменным заявлением.  
2. Подать жалобу в трудовую инспекцию.  
3. При необходимости обратиться в суд.  
*Статьи: Трудовой кодекс РФ, раздел о трудоустройстве несовершеннолетних.*

**Q:** Объясни что такое испытательный срок

**[DEBUG]**  
Query: Объясни что такое испытательный срок  
Type: law_info  
Hybrid Top-K: ['lc_rf_article_22_1.md', 'lc_rf_article_18.md', 'lc_rf_article_19_1.md']  

**A:** Испытательный срок — период для проверки соответствия сотрудника требованиям должности.  
Позволяет оценить навыки и пригодность к работе перед заключением постоянного трудового договора.  
Длительность определяется законом и условиями трудового договора.
