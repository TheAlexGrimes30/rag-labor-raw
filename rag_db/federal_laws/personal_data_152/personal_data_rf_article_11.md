# Статья 11 Федерального закона № 152-ФЗ
## Биометрические персональные данные

Статья регулирует обработку биометрических персональных данных, используемых для установления личности человека. По общему правилу для такой обработки требуется специальное согласие субъекта, за исключением прямо установленных законом случаев.

## Ключевые правила

1. Статья регулирует обработку биометрических персональных данных, используемых для установления личности человека.
2. По общему правилу для такой обработки требуется специальное согласие субъекта, за исключением прямо установленных законом случаев.
