# Статья 10.1 Федерального закона № 152-ФЗ
## Особенности обработки персональных данных, разрешенных субъектом персональных данных для распространения

Статья регулирует обработку персональных данных, которые субъект разрешил для распространения. Для такого распространения применяется специальное согласие, а субъект может устанавливать запреты и условия обработки либо требовать прекращения передачи и распространения в предусмотренном законом порядке.

## Ключевые правила

1. Статья регулирует обработку персональных данных, которые субъект разрешил для распространения.
2. Для такого распространения применяется специальное согласие, а субъект может устанавливать запреты и условия обработки либо требовать прекращения передачи и распространения в предусмотренном законом порядке.
