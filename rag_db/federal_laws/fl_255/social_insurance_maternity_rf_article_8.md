# Статья 8 Федерального закона № 255-ФЗ
## Основания для снижения размера пособия по временной нетрудоспособности

Статья устанавливает основания, при которых размер пособия по временной нетрудоспособности может быть снижен.

## Основные положения

Статья устанавливает основания, при которых размер пособия по временной нетрудоспособности может быть снижен.

## Ключевые правила

1. Статья регулирует вопрос: **основания для снижения размера пособия по временной нетрудоспособности**.
2. Положение применяется в системе обязательного социального страхования на случай временной нетрудоспособности и в связи с материнством.
3. При применении статьи необходимо учитывать связанные нормы Федерального закона № 255-ФЗ, ТК РФ и законодательства об обязательном социальном страховании.
