# Статья 18 Федерального закона № 426-ФЗ
## Федеральная государственная информационная система учета результатов проведения специальной оценки условий труда

Статья регулирует федеральную государственную информационную систему учета результатов СОУТ, состав передаваемых сведений, обязанности участников по их передаче и использование данных для государственного учета и контроля.

## Основные положения

Статья регулирует федеральную государственную информационную систему учета результатов СОУТ, состав передаваемых сведений, обязанности участников по их передаче и использование данных для государственного учета и контроля.

## Ключевые правила

1. Статья регулирует федеральную государственную информационную систему учета результатов СОУТ, состав передаваемых сведений, обязанности участников по их передаче и использование данных для государственного учета и контроля.
2. Положение применяется во взаимосвязи с иными нормами 426-ФЗ, ТК РФ и нормативными требованиями охраны труда.
