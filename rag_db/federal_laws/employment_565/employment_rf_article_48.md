# Статья 48 Федерального закона № 565-ФЗ
## Особенности назначения пособия по безработице гражданам предпенсионного возраста

Статья устанавливает специальные правила назначения и продолжительности выплаты пособия по безработице гражданам предпенсионного возраста.

## Продолжительность выплаты

Для предусмотренных статьей граждан предпенсионного возраста период выплаты пособия может составлять до **12 месяцев в суммарном исчислении в течение 18 месяцев**.

Из этого правила предусмотрены исключения для отдельных категорий граждан.

## Увеличение периода выплаты

Для граждан с длительным страховым стажем период выплаты может увеличиваться сверх 12 месяцев.

Увеличение производится на две недели за каждый год страхового стажа, превышающего установленную законом продолжительность, при соблюдении предусмотренных условий.

## Связь со страховым стажем

При определении права на увеличенный период учитываются:

- страховой стаж;
- при необходимости стаж на соответствующих видах работ, дающий право на досрочную страховую пенсию.

## Ключевые правила

1. Для граждан предпенсионного возраста установлен особый период выплаты пособия.
2. В предусмотренных случаях он может достигать 12 месяцев в течение 18 месяцев.
3. При длительном страховом стаже период выплаты может дополнительно увеличиваться.
4. Увеличение составляет две недели за каждый соответствующий дополнительный год страхового стажа.
5. При применении статьи учитываются специальные правила законодательства о страховых пенсиях.
