# Статья 39 Федерального закона № 565-ФЗ
## Специальные рабочие места для трудоустройства инвалидов

Статья определяет понятие специального рабочего места для трудоустройства инвалида и устанавливает правила его оснащения.

## Понятие специального рабочего места

Специальное рабочее место для трудоустройства инвалида — рабочее место, которое требует дополнительных мер по организации труда.

Такие меры могут включать:

- адаптацию основного оборудования;
- адаптацию вспомогательного оборудования;
- специальное техническое оснащение;
- специальное организационное оснащение;
- дополнительное оснащение рабочего места;
- использование технических приспособлений с учетом индивидуальных возможностей инвалида.

## Оснащение рабочего места

Работодатель оборудует специальное рабочее место с учетом:

- нарушенных функций инвалида;
- ограничений его жизнедеятельности;
- основных требований к оснащению специальных рабочих мест, установленных уполномоченным федеральным органом.

## Количество специальных рабочих мест

Количество специальных рабочих мест устанавливается исполнительными органами субъектов Российской Федерации для каждого работодателя.

Оно определяется **в пределах установленной работодателю квоты для приема на работу инвалидов**.

## Ключевые правила

1. Специальное рабочее место предполагает дополнительные меры по организации труда.
2. Оборудование рабочего места должно учитывать индивидуальные возможности инвалида.
3. Допускается адаптация оборудования и использование специальных технических приспособлений.
4. Работодатель обязан соблюдать установленные требования к оснащению таких рабочих мест.
5. Количество специальных рабочих мест определяется органами субъектов РФ.
6. Специальные рабочие места устанавливаются в пределах квоты для приема инвалидов.
