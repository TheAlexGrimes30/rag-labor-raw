# Статья 333 ТК РФ
## Продолжительность рабочего времени педагогических работников

Статья устанавливает сокращенную продолжительность рабочего времени педагогических работников и определяет основы регулирования их педагогической и учебной нагрузки.

## Сокращенная продолжительность рабочего времени

Для педагогических работников устанавливается **сокращенная продолжительность рабочего времени — не более 36 часов в неделю**.

Следовательно, для педагогических работников применяется специальное правило о продолжительности рабочей недели.

## Особенности продолжительности рабочего времени

Конкретная продолжительность рабочего времени педагогического работника определяется с учетом:

- занимаемой должности;
- специальности;
- особенностей выполняемого труда.

Для разных категорий педагогических работников могут устанавливаться различные нормы рабочего времени и педагогической нагрузки.

## Норма часов педагогической работы

В зависимости от должности и специальности устанавливается **норма часов педагогической работы за ставку заработной платы**.

Таким образом, статья разграничивает общую сокращенную продолжительность рабочего времени и нормы непосредственно педагогической работы за ставку заработной платы.

## Учебная нагрузка

Для педагогических работников устанавливаются специальные правила определения учебной нагрузки.

Регулируются:

- порядок определения учебной нагрузки;
- порядок ее оплаты;
- основания изменения учебной нагрузки;
- случаи установления верхнего предела учебной нагрузки.

Учебная нагрузка педагогического работника оговаривается в трудовом договоре.

## Дополнительная работа

Педагогический работник может наряду с работой, предусмотренной трудовым договором, выполнять дополнительную работу.

Для выполнения такой работы требуется **письменное согласие педагогического работника**.

Специальными нормативными правилами устанавливаются:

- случаи выполнения дополнительной работы;
- порядок ее выполнения;
- условия выполнения;
- условия оплаты такой работы.

## Кто устанавливает специальные правила

Для педагогических работников профессорско-преподавательского состава соответствующие правила устанавливаются федеральным органом исполнительной власти, осуществляющим функции по выработке и реализации государственной политики и нормативно-правовому регулированию в сфере высшего образования.

Для иных педагогических работников соответствующее регулирование осуществляется федеральным органом исполнительной власти в сфере общего образования.

При установлении этих правил учитывается мнение Российской трехсторонней комиссии по регулированию социально-трудовых отношений.

## Ключевые правила

1. Педагогическим работникам устанавливается сокращенная рабочая неделя.
2. Ее продолжительность не может превышать **36 часов в неделю**.
3. Конкретные нормы рабочего времени зависят от должности, специальности и особенностей труда.
4. Для педагогических работников устанавливаются нормы часов педагогической работы за ставку заработной платы.
5. Учебная нагрузка оговаривается в трудовом договоре.
6. Специально регулируются порядок определения и оплаты учебной нагрузки.
7. Предусматриваются основания изменения учебной нагрузки и случаи установления ее верхнего предела.
8. Дополнительная работа наряду с предусмотренной трудовым договором выполняется с письменного согласия педагогического работника.
9. Условия и порядок выполнения дополнительной работы, включая ее оплату, определяются специальными нормативными правилами.
