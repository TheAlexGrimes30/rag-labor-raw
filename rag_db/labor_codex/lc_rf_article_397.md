# Статья 397 ТК РФ
## Ограничение обратного взыскания сумм, выплаченных по решению органов, рассматривающих индивидуальные трудовые споры

Статья ограничивает возможность взыскать обратно с работника суммы, полученные им по решению органа по рассмотрению индивидуального трудового спора.

## Общее правило

При последующей отмене решения обратное взыскание выплаченных работнику сумм допускается только в специально установленном случае.

## Основания обратного взыскания

Обратное взыскание возможно, если отмененное решение было основано:

- на ложных сведениях, сообщенных работником;
- на подложных документах, представленных работником.

## Ключевые правила

1. Отмена решения сама по себе не означает автоматического возврата работником полученных сумм.
2. Обратное взыскание допускается при недобросовестных действиях работника, прямо указанных в статье.
3. Основанием могут быть ложные сведения или подложные документы.
