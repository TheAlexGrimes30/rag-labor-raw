# Статья 59 ТК РФ
## Срочный трудовой договор

### 1. Случаи обязательного заключения срочного трудового договора

Срочный трудовой договор заключается, если характер работы или условия её выполнения требуют временного характера трудовых отношений, в том числе:

- на время исполнения обязанностей отсутствующего работника, за которым сохраняется место работы;
- на время выполнения временных работ (до двух месяцев);
- для выполнения сезонных работ;
- с работниками, направляемыми на работу за границу;
- для выполнения работ, выходящих за рамки обычной деятельности работодателя (например, реконструкция, монтаж, пусконаладочные работы);
- при временном расширении производства или объёма услуг (до одного года);
- с лицами, поступающими в организации, созданные на заведомо ограниченный срок;
- для выполнения заведомо определённой работы, завершение которой не может быть определено конкретной датой;
- для работ, связанных с обучением, практикой или стажировкой;
- при избрании на выборную должность на определённый срок;
- с лицами, направленными службой занятости на временные или общественные работы;
- с гражданами, проходящими альтернативную гражданскую службу;
- в иных случаях, предусмотренных Трудовым кодексом или федеральными законами.

---

### 2. Срочный трудовой договор по соглашению сторон

По соглашению сторон срочный трудовой договор может заключаться, в частности:

- с работодателями — субъектами малого предпринимательства;
- с пенсионерами по возрасту;
- с лицами, которым по состоянию здоровья разрешена только временная работа;
- с работниками, переезжающими в районы Крайнего Севера;
- при проведении неотложных работ по предотвращению катастроф, аварий, эпидемий;
- с лицами, принятыми по результатам конкурса;
- с творческими работниками СМИ, театров, кино и иных организаций;
- с руководителями организаций, их заместителями и главными бухгалтерами;
- со студентами очной формы обучения;
- с членами экипажей судов;
- при работе по совместительству;
- с работниками некоммерческих организаций малого размера;
- в иных случаях, предусмотренных законом.

---

## Краткое содержание

Статья 59 ТК РФ устанавливает перечень оснований для заключения срочного трудового договора.  
Основания делятся на две группы: обязательные случаи, обусловленные характером работы, и случаи, допускаемые по соглашению сторон.
