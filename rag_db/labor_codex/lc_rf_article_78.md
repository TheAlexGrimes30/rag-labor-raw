# Статья 78 ТК РФ
## Расторжение трудового договора по соглашению сторон

### Расторжение по соглашению сторон

Трудовой договор может быть расторгнут по соглашению сторон трудового договора.

---

### Срок расторжения

По соглашению сторон трудовой договор может быть расторгнут:

- в любое время

Основанием для расторжения является соглашение сторон трудового договора.
