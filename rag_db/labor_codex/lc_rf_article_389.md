# Статья 389 ТК РФ
## Исполнение решений комиссии по трудовым спорам

Статья регулирует исполнение решений комиссии по трудовым спорам.

## Добровольное исполнение

Решение КТС подлежит исполнению в течение трех дней после истечения десятидневного срока, предусмотренного для его обжалования.

## Удостоверение КТС

Если решение не исполнено, комиссия выдает работнику удостоверение, являющееся исполнительным документом.

За удостоверением можно обратиться в течение одного месяца со дня принятия решения. Пропущенный по уважительной причине срок может быть восстановлен.

Удостоверение не выдается, если работник или работодатель своевременно перенес спор в суд.

## Принудительное исполнение

Удостоверение может быть предъявлено для принудительного исполнения судебному приставу в течение трех месяцев со дня его получения. Пропущенный по уважительной причине срок может быть восстановлен КТС.

## Ключевые правила

1. Решение КТС исполняется после истечения срока обжалования.
2. При неисполнении работнику выдается исполнительное удостоверение.
3. За удостоверением следует обратиться в течение одного месяца.
4. Для предъявления удостоверения к принудительному исполнению установлен трехмесячный срок.
