# Статья 125 ТК РФ
## Разделение ежегодного оплачиваемого отпуска на части. Отзыв из отпуска

### Разделение ежегодного оплачиваемого отпуска

Ежегодный оплачиваемый отпуск может быть разделен на части:

- по соглашению между работником и работодателем

---

### Минимальная продолжительность одной части отпуска

При разделении ежегодного оплачиваемого отпуска:

- хотя бы одна из частей отпуска должна составлять не менее 14 календарных дней

---

### Отзыв работника из отпуска

Отзыв работника из ежегодного оплачиваемого отпуска допускается:

- только с согласия работника
- за исключением случаев, предусмотренных Трудовым кодексом Российской Федерации

---

### Неиспользованная часть отпуска после отзыва

Часть отпуска, не использованная работником в связи с отзывом, должна быть предоставлена:

- по выбору работника
- в удобное для работника время в течение текущего рабочего года

Либо неиспользованная часть отпуска может быть:

- присоединена к отпуску за следующий рабочий год

---

### Работники, которых нельзя отзывать из отпуска

Не допускается отзыв из отпуска:

- работников в возрасте до восемнадцати лет
- беременных женщин
- работников, занятых на работах с вредными условиями труда
- работников, занятых на работах с опасными условиями труда

---

---

### Ключевые правила

- ежегодный оплачиваемый отпуск может быть разделен на части только по соглашению работника и работодателя
- хотя бы одна часть разделенного отпуска должна составлять не менее 14 календарных дней
- отзыв работника из отпуска по общему правилу допускается только с его согласия
- неиспользованная после отзыва часть отпуска предоставляется по выбору работника в удобное время текущего рабочего года либо присоединяется к отпуску за следующий рабочий год
- несовершеннолетних работников нельзя отзывать из отпуска
- беременных женщин нельзя отзывать из отпуска
- работников с вредными или опасными условиями труда нельзя отзывать из отпуска
