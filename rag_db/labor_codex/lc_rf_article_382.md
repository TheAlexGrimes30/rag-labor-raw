# Статья 382 ТК РФ
## Органы по рассмотрению индивидуальных трудовых споров

Статья определяет органы, уполномоченные рассматривать индивидуальные трудовые споры.

## Органы рассмотрения споров

Индивидуальные трудовые споры рассматриваются:

- комиссиями по трудовым спорам;
- судами.

Иной порядок может быть установлен непосредственно Трудовым кодексом Российской Федерации.

## Ключевые правила

1. Основными органами разрешения индивидуальных трудовых споров являются комиссия по трудовым спорам и суд.
2. Для отдельных споров ТК РФ может устанавливать специальный порядок рассмотрения.
