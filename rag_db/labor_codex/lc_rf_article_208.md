# Статья 208 ТК РФ
## Основания прекращения ученического договора

Ученический договор прекращается по окончании срока обучения либо по основаниям, предусмотренным самим ученическим договором.

## Основные положения

Ученический договор прекращается по окончании срока обучения либо по основаниям, предусмотренным самим ученическим договором.

## Ключевые правила

1. Ученический договор прекращается по окончании срока обучения либо по основаниям, предусмотренным самим ученическим договором.
2. Положение применяется с учетом связанных норм ТК РФ и иных нормативных правовых актов.
